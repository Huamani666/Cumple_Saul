# Página Web de Cumpleaños para Saúl Cristian 🤘🔥

Página interactiva temática de Heavy Metal & Rock desarrollada para el cumpleaños de **Saúl Cristian**.

## 🚀 Características
- **Optimizado para Móviles:** Diseño 100% responsive y controles con soporte para gestos táctiles (Swipe en carrusel).
- **Carrusel de Fotos Interactivo:** Permite visualizar fotos y subir nuevas imágenes directamente.
- **Sintetizador de Riffs Metal:** Generador de audio en tiempo real creado con Web Audio API y visualizador dinámico de barras.
- **Soundboard Interactivo:** Efectos de sonido de batería (doble pedal), solo rápido de guitarra y ovaciones del público.
- **Efectos Visuales Canvas:** Lluvia interactiva de púas de guitarra y chispas de fuego.
- **Botón directo a WhatsApp:** Comparte el saludo de cumpleaños en un clic.

## 📦 Publicar en GitHub Pages

1. Sube los archivos `index.html` y `README.md` a tu repositorio de GitHub.
2. Ve a la pestaña **Settings** (Configuración) de tu repositorio.
3. Entra a la sección **Pages** (en el menú lateral).
4. En **Source**, selecciona la rama `main` (o `master`) y la carpeta `/ (root)`.
5. Presiona **Save**. En 1 o 2 minutos GitHub te entregará el enlace público para enviárselo a Saúl.
